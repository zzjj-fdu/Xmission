# 2026-10-02 审查问题修复

## 已处理

- 普通任务、循环任务和步骤：完成与撤销在 `BEGIN IMMEDIATE` 事务内读取状态、执行状态转换、结算经验和金币、更新连击；重复请求返回现有结果。取消完成后允许重新完成并重新结算。
- 结算助手要求传入事务，钱包与状态事件在提交成功后才广播。任务补丁不能绕过完成／撤销入口改变完成状态。
- 商店：在同一写事务内校验余额、扣库存、记录兑换、扣款；抽奖也使用同一写事务规则校验余额。
- 任务更新：区分未传字段、明确传 `null` 和传值；备注、截止时间、预估耗时、计划日期和循环星期可以清空。
- 备注：编辑器入口和悬浮窗显示统一使用 DOMPurify，保留编辑器支持的格式和字号，移除脚本、事件、外部链接与任意样式；启用生产环境 CSP。
- AI：外部接口强制 HTTPS，仅本机回环地址允许 HTTP；拒绝地址内嵌账号密码，网络客户端不自动跟随重定向。通用设置入口不能修改 AI 或抽奖专用配置。
- JSON 备份：包含 `lottery_draws`，在一致的读事务内导出；文件名增加 UUID，并以 `create_new` 写入，避免覆盖；写入失败清理本次不完整文件。
- 番茄钟：替换、暂停、恢复、完成都在写事务内执行；任务不存在或写入失败保留原会话；完成结算也具备幂等性。迁移保留最新活跃会话并把历史重复活跃会话标为 abandoned，新增只允许一个活跃会话的数据库约束。
