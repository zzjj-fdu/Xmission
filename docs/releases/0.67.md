# Xmission 0.67

Windows 10/11 x64 桌面版（构建版本 0.67.0）。

- 任务、步骤、备注与重复目标；XP、金币、自定义商店奖励和主题抽奖。
- Excel/CSV 和 AI 课表识别、校对、学校作息模板、合并连堂与日历弹窗。
- 主窗口托盘驻留、单实例、独立悬浮任务栏、可拖动悬浮球和开机启动设置。
- 可设置时长的全屏番茄钟，启动后保留时间与场景，移除毛玻璃时间背景板。
- 四套主题、24 张六时段风景、本地天气叠层、可选联网天气和减少动态效果。
- 四主题屋顶积雪、地面雪带及雨天积水与涟漪。
- 任务和步骤结算幂等、原子奖励事务、并发兑换保护、备注净化和备份完整性修复。

## 安装与数据

安装包不携带开发者的数据库、备份、任务、课程、钱包进度、API Key 或系统凭据。
首次运行创建使用者自己的本地数据库，AI 功能需要使用者在设置中配置自己的服务。
升级前可在设置中导出备份，已有本机数据不会被开发数据替换。

许可沿用仓库的 PolyForm Noncommercial 1.0.0；字体许可见 public/fonts。
