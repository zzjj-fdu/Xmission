# Windows 0.67 安装包修复

原 Windows 安装包漏带主程序依赖的 `WebView2Loader.dll`，导致首次启动出现系统错误，重复安装无法解决。

修正版为 [`Xmission_0.67.0_x64-fixed-setup.exe`](https://github.com/zzjj-fdu/Xmission/releases/download/v0.67/Xmission_0.67.0_x64-fixed-setup.exe)，仍使用 0.67.0 应用版本及原有应用标识。直接覆盖安装即可，无需删除数据库或清空任务、课表和 API 配置。

本次重新打包原 0.67 Windows 主程序，并包含同一构建生成的 Microsoft 签名 x64 加载器；不纳入开发中的其他功能，不包含开发者数据或密钥。已检查 NSIS 文件清单、DLL 架构，并在独立空数据目录及仅系统 PATH 环境中验证程序启动。

## 后续 Windows 构建

从项目根目录运行：

```powershell
powershell -NoProfile -File scripts/build-windows-release.ps1
```

脚本显式传递当前 Windows x64 Rust target，并检查主程序导入及 NSIS 是否包含必要的 DLL。此检查失败时不可发布安装包。GNU 构建需要可用的 MinGW 工具链；MSVC 构建需要 Visual C++ 构建工具。
