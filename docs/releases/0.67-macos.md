# Xmission 0.67 · macOS 测试版

本次为 macOS 适配发布，应用版本为 **0.67.0**。Windows 版仍在 `v0.67` 发布页。

- **Universal DMG**：同一安装包支持 Apple 芯片（arm64）与 Intel（x86_64），最低 macOS 11。
- 安装：打开 DMG，将 Xmission 拖入 Applications 文件夹。
- API 密钥使用 macOS 系统钥匙串；安装包不携带开发者的本地数据库、API 密钥或备份。
- 适配透明悬浮窗、悬浮球拖动和菜单栏托盘；开机启动目前仅支持 Windows，macOS 不显示该选项。
- 构建流程检查两种架构、临时签名、DMG 完整性，并用独立空数据目录进行启动检查。

## 测试版限制

当前使用 **ad-hoc 临时签名**，尚未使用 Apple Developer ID 签名和公证。macOS 可能阻止首次打开；请自行确认下载来源及系统提示。尚未完成真实 Mac 上的完整交互验收。

附带 `SHA256SUMS-macos.txt` 供校验安装包。
