pub struct Step { id, task_id, parent_step_id, title, order_index: i64,
  deadline: Option<String>, estimated_min: Option<i64>, surface_days: Option<i64>,

### 2.2 番茄钟（新文件 `pomodoro.rs`）

```rust
pub struct PomodoroSession { id, task_id: Option<String>, task_title: Option<String>,
  started_at, duration_min: i64, state: String, remaining_secs: i64, updated_at: String }

pomodoro_start(task_id: Option<String>) -> PomodoroSession
  // duration 取 settings.pomodoro_work_min（缺省 25）；task_title 联表带出；
  // 已有 running/paused 会话则先把它标记 abandoned（同时只允许一个活跃会话）
pomodoro_pause() -> PomodoroSession    // running→paused，冻结 remaining_secs
pomodoro_resume() -> PomodoroSession   // paused→running，updated_at=now
pomodoro_finish(completed: bool) -> () // →done/abandoned；completed=true 时结算 XP 5 / 金币 2（reason="pomodoro"）
pomodoro_current() -> Option<PomodoroSession>  // 只返回 running/paused
```

- 前端倒计时推导：`state=running` → 剩余 = `remaining_secs - (now - updated_at)`；`paused` → `remaining_secs`。
- 每次状态变更 `app.emit("pomodoro-changed", Option<PomodoroSession>)`（finish 后发 None）。
- 启动崩溃恢复：lib.rs `setup` 里在 pool init 后把残留 running 会话改成 paused（`freeze_orphan_sessions`）。

### 2.3 游戏化（新文件 `gamification.rs`）

```rust
pub struct Wallet { xp_total: i64, coins: i64, level: i64,
  xp_into_level: i64, xp_to_next: i64, streak: i64 }  // → xpTotal/coins/level/xpIntoLevel/xpToNext/streak

get_wallet() -> Wallet
```

- **XP 公式（固定，勿自创）**：
  - 完成任务：`xp = 5 + 3×importance + min(estimated_min÷10, 20)`（无估时按 0）；`coins = max(1, xp÷2)`
  - 完成步骤：`xp = 3 + 父任务importance`；`coins = max(1, xp÷2)`
  - 完成番茄钟：`xp = 5, coins = 2`
- **等级曲线**：升到 n+1 级需 `100×n` XP（即 xpToNext = 100×level；xpIntoLevel/xpToNext 由此推出）。
- **Streak（任务日 = 本地时间减 4 小时后的日期，spec §9）**：结算时 `today==last_active_date` 不变；`today==last+1` → current+1；否则 current=1；更新 last_active_date。
- 结算写 xp_ledger + coin_ledger（reason: "task" | "step" | "pomodoro" | "redeem"），然后 emit "wallet-updated"（payload = Wallet）。
- 接入点：`task_engine::complete_task` 更新库后调用 `gamification::settle_task(&pool, &app, &task)`；`complete_step`、`pomodoro_finish` 同理。reopen 不回滚。
