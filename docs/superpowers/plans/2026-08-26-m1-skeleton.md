# Xmission M1 骨架阶段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建 Xmission 可运行的 M1 骨架：Tauri 双窗口（悬浮任务栏 + 主窗口）+ SQLite 持久化 + 任务 CRUD + 悬浮栏打勾 + 像素 JRPG 默认皮肤。

**Architecture:** Tauri 2.x 单进程双 WebView 窗口；前端 React 18 + TS + Vite，两个入口（`index.html` 主窗口 / `widget.html` 悬浮栏）；Rust 侧 `task_engine` 模块通过 sqlx 操作 SQLite，前端经 Tauri Commands 调用、Events 接收刷新通知。皮肤采用 design tokens 架构，一期默认 `pixel-jrpg`。

**Tech Stack:** Tauri 2, React 18, TypeScript, Vite 6, Tailwind CSS 4, Zustand, Framer Motion, sqlx (SQLite), tokio, serde, chrono, uuid.

**Spec:** `docs/superpowers/specs/2026-08-26-gamified-taskbar-design.md`（M1 范围：FR-01 任务 CRUD、FR-03 悬浮栏、V2 像素 JRPG 默认皮肤；步骤树/番茄钟/游戏化属 M2+，本计划只在 DDL 中预留 `task_steps` 表）

- 应用代号 **Xmission**；Tauri identifier `com.xmission.app`；数据库文件 `xmission.db`

## 接口契约（跨 Task 的唯一事实来源）

**Rust → 前端 Tauri Commands**（参数/返回均为 serde JSON）：

```rust
// task_engine.rs
#[tauri::command] async fn create_task(state, input: CreateTaskInput) -> Result<Task, String>
#[tauri::command] async fn update_task(state, id: String, patch: UpdateTaskPatch) -> Result<Task, String>
#[tauri::command] async fn complete_task(state, id: String) -> Result<Task, String>   // status→done, completed_at=now
#[tauri::command] async fn reopen_task(state, id: String) -> Result<Task, String>     // status→open, completed_at=NULL
#[tauri::command] async fn delete_task(state, id: String) -> Result<(), String>
#[tauri::command] async fn list_tasks(state, filter: TaskFilter) -> Result<Vec<Task>, String>
```

```rust
pub struct Task { id: String, title: String, notes: Option<String>, form: String,
  importance: i64, urgency: i64, deadline: Option<String>, estimated_min: Option<i64>,
  status: String, parent_id: Option<String>, xp_value: i64, created_at: String,
  completed_at: Option<String> }
pub struct CreateTaskInput { title: String, notes: Option<String>, form: String,
  importance: Option<i64>, urgency: Option<i64>, deadline: Option<String>,
  estimated_min: Option<i64>, parent_id: Option<String> }
pub struct UpdateTaskPatch { title: Option<String>, notes: Option<String>,
  importance: Option<i64>, urgency: Option<i64>, deadline: Option<String>,
  estimated_min: Option<i64>, status: Option<String> }
pub struct TaskFilter { status: Option<String>, form: Option<String> }  // 全 None = 全部
```

**事件**：每次写操作成功后 emit `tasks-changed`（无 payload）。前端 store 监听后重新拉取。

**前端 API 封装** `src/api/tasks.ts` 导出与上同名的 async 函数 + `Task`/`CreateTaskInput`/`UpdateTaskPatch`/`TaskFilter` 类型 + `onTasksChanged(cb): Promise<UnlistenFn>`。
