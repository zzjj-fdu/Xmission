# 六时段风景与天气

## 图片

使用内置 image_gen 编辑原始四套风景，独立生成 24 张图片。每张都引用对应主题的原始场景，保持城堡、房屋、桥、田地、河流与山脉的位置；仅修改光线、天空与环境氛围。未把雨、雪等粒子烘焙进背景。

- 原始生成图片：本地 `source/`（不提交；公开版本包含压缩运行图片）
- 完整提示集：`prompts.json`
- 四主题 × 六时段总览：`overview.jpg`
- 运行图片：项目 `public/scenes/`，WebP、最长边 1920、质量 84。
- 图片清单与大小：`manifest.json`。24 张共 7,187,728 字节，相比 PNG 约减少 89%。

## 时段规则

按电脑本地时间：00:00–04:59 凌晨，05:00–06:59 晨曦，07:00–10:59 早上，11:00–15:59 正午，16:00–18:59 夕阳，19:00–23:59 灯火夜晚。

初次启动选择当前时段。主窗口隐藏到托盘后重新打开时更新时段；保持打开、最小化、切换页面或设置天气时不更换时段。切换皮肤造成页面刷新时保留当前时段。实时天气的城市不改变电脑本地时段。

## 程序天气

晴、多云、雨、雪、风、雾使用同一张当前时段背景，叠加轻量 CSS/SVG。JRPG 使用像素雨、星光和夜间流星；手账使用纸尘、水痕；小岛使用花瓣和圆润雨滴；农场使用夜间萤火虫、落叶和与屋顶位置对齐的积雪。

最多 29 个粒子，只有当前显示的风景层运行；隐藏、最小化或页面不可见时暂停。取消每分钟的时间轮询，把秒级专注计时更新限制在计时器组件。减少动态效果及关闭动画保留静态天气氛围，不生成动画粒子；也遵循系统的减少动态效果偏好。缓存实时天气，离线回退用户选择，主窗口收起时停止定期刷新。

## 检查

`npm run check`：TypeScript，以及真实时段函数、窗口会话生命周期、天气回退/设置保存、24 张资源完整性与大小。

Windows GNU 下运行原有 Rust 测试请使用 `scripts/check-native.ps1`。它为测试程序链接 Tauri 已生成的 Common Controls v6 清单，避免 TaskDialogIndirect 入口缺失；这项测试配置不影响正常应用构建。

原生控件说明：[Microsoft Task Dialogs](https://learn.microsoft.com/en-us/windows/win32/controls/create-task-dialogs)。构建参数说明：[Cargo build scripts](https://doc.rust-lang.org/cargo/reference/build-scripts.html#rustc-link-arg)。

独立预览：`npx tauri build --no-bundle --ci`，不生成安装包。
